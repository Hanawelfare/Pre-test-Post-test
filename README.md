# แบบวัดผลการปฐมนิเทศ พนักงานรายวัน (Orientation Exam System)

ระบบแบบวัดผลการปฐมนิเทศสำหรับพนักงานใหม่ (พนักงานรายวัน) แยกเป็นระบบเฉพาะโดยไม่กระทบกับระบบข้อสอบเดิม ออกแบบด้วย UI ที่ทันสมัย ใช้งานสะดวกทั้งบนสมาร์ทโฟนและคอมพิวเตอร์ เชื่อมต่อ Google Sheets แบบ Real-time

---

## 🌟 จุดเด่นและเงื่อนไขการทำงานของระบบใหม่

1. **เงื่อนไขการให้คะแนนและเกณฑ์ผ่าน (Scoring Rules):**
   - ข้อสอบทั้งหมด **25 ข้อ** (คะแนนเต็ม 25 คะแนน)
   - **ตอบถูก:** ได้ **1 คะแนน**
   - **ตอบผิด หรือ ไม่ตอบ:** ได้ **0 คะแนน** (ไม่มีการหักคะแนนติดลบ)
   - **เกณฑ์ผ่าน:** **80% ขึ้นไป** (ต้องได้ **20 คะแนนขึ้นไป**)

2. **ระบบบังคับตอบครบ 25 ข้อ (ห้ามข้ามส่งเด็ดขาด) & ระบบติดตามข้อที่ข้าม:**
   - **ไม่สามารถส่งข้อสอบได้หากยังตอบไม่ครบ 25 ข้อ:** ระบบจะบล็อกการส่งและแจ้งเตือนพร้อมระบุเลขข้อที่ยังไม่ได้ตอบ
   - **สามารถข้ามไปตอบข้ออื่นได้:** พนักงานสามารถกดเลือกทำข้อที่มั่นใจก่อนได้
   - **แถบแสดงข้อที่ข้ามชัดเจน:** มีแผงเลขข้อ 1-25 และแถบแสดงรายการข้อที่ข้ามไปเป็นปุ่มสีส้ม (เช่น `ข้อ 3, ข้อ 7, ข้อ 15`)
   - **ปุ่มวนกลับมาตอบทันที:** มีปุ่ม `[🔄 วนไปตอบข้อที่ข้ามถัดไป]` ช่วยนำทางพนักงานกลับมาตอบข้อที่ข้ามไปจนครบทั้ง 25 ข้อได้อย่างสะดวกรวดเร็ว

3. **ระบบสลับข้อสอบเฉพาะบุคคล (ป้องกันการลอกคำตอบกัน):**
   - ระบบใช้ Fisher-Yates Shuffle Algorithm สุ่มสลับลำดับโจทย์ 25 ข้อแบบเฉพาะบุคคลในทุกรอบการสอบ
   - พนักงานที่นั่งติดกันจะได้รับลำดับคำถามไม่เหมือนกันอย่างสิ้นเชิง ป้องกันการลอกคำตอบกันได้อย่างมีประสิทธิภาพ

4. **ระบบ Auto-fill ข้อมูลพนักงาน:**
   - พนักงานพิมพ์เพียง **รหัสพนักงาน (Employee ID)** ระบบจะค้นหาและเติม **ชื่อ-นามสกุล** และ **แผนก** ให้โดยอัตโนมัติจากแท็บ `Name` ใน Google Sheet ทันที

5. **ปุ่มทำข้อสอบใหม่ (ครั้งที่ ...) เมื่อสอบไม่ผ่าน:**
   - หากพนักงานทำคะแนนได้น้อยกว่า 80% (< 20 คะแนน) จะมีปุ่มเด่นชัดขึ้นมาให้ **"ทำข้อสอบใหม่ (ครั้งที่ ...)"** เพื่อให้พนักงานกดทำซ้ำได้ทันที
   - ระบบจะนับและบันทึกจำนวนครั้งที่ทำให้อัตโนมัติ (ครั้งที่ 1, ครั้งที่ 2, ครั้งที่ 3...)

6. **มุมมองคะแนนของพนักงาน (ความโปร่งใสและป้องกันการจำเฉลย):**
   - พนักงานจะทราบเฉพาะ **คะแนนรวม (เช่น 22/25)**, **คิดเป็น % (เช่น 88%)**, และ **สถานะ (ผ่าน/ไม่ผ่าน)**
   - ระบบ **ไม่แสดงเฉลยคำตอบรายข้อ** ให้พนักงานเห็น เพื่อป้องกันการจำเฉลยไปตอบในรอบทำใหม่

7. **แดชบอร์ดติดตามผลสอบ (Dashboard สำหรับทั้งแอดมินและพนักงาน):**
   - มีเมนู **"แดชบอร์ดติดตามผลสอบ"** ด้านบน ให้ทั้งพนักงานและแอดมินคลิกดูความคืบหน้าได้ตลอดเวลา
   - มีการ์ดสรุปและตารางแสดงสถานะ 3 กลุ่มอย่างชัดเจน:
     - 🟢 **สอบผ่าน (PASS):** ผู้ที่ทำคะแนนได้ตั้งแต่ 80% ขึ้นไป (≥ 20 คะแนน)
     - 🔴 **ยังไม่ผ่าน (FAIL):** ผู้ที่สอบแล้วแต่ยังไม่ถึง 80% (ต้องทำใหม่) พร้อมแสดงว่าทำไปกี่ครั้งแล้ว
     - 🟡 **ยังไม่เสร็จ / ยังไม่ได้สอบ (PENDING):** พนักงานในฐานข้อมูลที่ยังไม่ได้เข้าทำข้อสอบ
   - มีระบบค้นหาตามรหัสพนักงาน ชื่อ แผนก และตัวกรองสถานะ
   - มีปุ่มส่งออกรายงานเป็นไฟล์ **CSV**

8. **บันทึกลง Google Sheet:**
   - บันทึกข้อมูล วันเวลา, รหัสพนักงาน, ชื่อ-นามสกุล, แผนก, ประเภทข้อสอบ, คะแนน, %, ผลสอบ, และรอบที่ทำ ลงใน Google Sheet เรียลไทม์

```
│   ├── quiz.js                # Quiz Engine (25 ข้อ, เกณฑ์ 80%, นับรอบสอบ)
│   ├── app.js                 # Controller, Auto-fill, Dashboard & Retest
│   ├── questions.json         # ชุดคำถาม 25 ข้อพร้อมเฉลย
│   ├── google-script/
│   │   └── Code.gs            # โค้ด Apps Script รองรับทั้งระบบเดิมและระบบใหม่
│   └── README.md              # คู่มือการใช้งานระบบ
```

## 🛠️ การตั้งค่า Google Sheets

ระบบตั้งค่าให้เชื่อมต่อกับ Google Apps Script Web App เดิมของคุณไว้อัตโนมัติเรียบร้อยแล้ว:
`https://script.google.com/macros/s/AKfycbwvYgRcvzKO7pdGhcGXgrUFF3XW2ENMhhulJlrWJuCHu_pyrVTKMzEWOme_fmVc5L5L/exec`

หากต้องการให้ผลสอบแยกเป็นแท็บ **`ผลสอบปฐมนิเทศ`** โดยเฉพาะ:
1. ไปที่ Google Sheet ของคุณ -> เมนู **ส่วนขยาย (Extensions)** -> **Apps Script**
2. คัดลอกโค้ดจาก `orientation/google-script/Code.gs` ไปวางแทนที่
3. กด **ทำให้ใช้งานได้ (Deploy)** -> **จัดการการทำให้ใช้งานได้ (Manage deployments)** -> กดไอคอนดินสอแก้ไข -> เลือกเวอร์ชันเป็น **เวอร์ชันใหม่ (New version)** -> กด **Deploy**

# ระบบข้อสอบ Pre-test & Post-test ออนไลน์ (เชื่อมต่อ Google Sheets)

ระบบข้อสอบออนไลน์ Pre-test และ Post-test แบบสลับโจทย์และตัวเลือกอัตโนมัติป้องกันการลอกกัน ออกแบบด้วย UI ที่ทันสมัย ใช้งานง่ายทั้งบนคอมพิวเตอร์และโทรศัพท์มือถือ พร้อมเชื่อมต่อ Google Sheets แบบ Real-time สำหรับ Auto-fill ข้อมูลพนักงานและบันทึกผลคะแนนสอบทันที

---

## 🌟 คุณสมบัติเด่น (Features)

1. **ระบบสลับข้อสอบ & ตัวเลือก (Shuffle Algorithm):**
   - สลับลำดับโจทย์ 20 ข้อ และสลับลำดับตัวเลือก (ถูก/ผิด) แบบสุ่มเฉพาะตัวบุคคลในทุกรอบการสอบ เพื่อป้องกันการลอกกัน
2. **กติกาการให้คะแนนตามกำหนด:**
   - **ตอบถูก:** +1 คะแนน
   - **ข้าม / ไม่ตอบ:** 0 คะแนน
   - **ตอบผิด:** -1 คะแนน
3. **ระบบ Auto-fill ข้อมูลพนักงาน:**
   - เพียงพิมพ์ **รหัสพนักงาน (Employee ID)** ระบบจะดึง **ชื่อ-นามสกุล** และ **แผนก** มาเติมให้อัตโนมัติ โดยดึงข้อมูลตรงจาก Google Sheet ของคุณ
4. **แสดงคะแนนและสรุปผล Real-time:**
   - พนักงานรู้ผลคะแนนทันทีหลังทำเสร็จ พร้อมบอกสถานะ **ผ่าน (PASS)** หรือ **ไม่ผ่าน (FAIL)** และสามารถกดดูเฉลยพร้อมคำอธิบายรายข้อได้อย่างละเอียด
5. **บันทึกผลคะแนนลง Google Sheet ทันที:**
   - ส่งผลสอบ (วันเวลา, รหัสพนักงาน, ชื่อ-นามสกุล, แผนก, ประเภท Pre/Post test, คะแนน, %, สถานะผ่าน/ไม่ผ่าน) เข้าไปสร้างบรรทัดใหม่ในตาราง Google Sheet เรียลไทม์
6. **จัดการคำถามได้ง่าย (Admin Question Editor):**
   - มีเมนู **Admin Editor** ให้ผู้ดูแลระบบแก้ไขคำถาม เปลี่ยนเฉลย (ถูก/ผิด) หรือเพิ่ม/ลดคำถามได้ผ่านหน้าเว็บโดยไม่ต้องแก้ไขโค้ด

## 🛠️ ขั้นตอนการติดตั้งการเชื่อมต่อ Google Sheets (ภายใน 2 นาที)

เพื่อให้ระบบสามารถ Auto-fill พนักงานและบันทึกคะแนนลงใน Google Sheet ของคุณตามลิงก์:
`https://docs.google.com/spreadsheets/d/1tmgXgn_inkEabJ5LzRLMa-zDLOf7hTW3CxGWKPPdu9I/edit`

ให้ทำตามขั้นตอนง่ายๆ ดังนี้:

### ขั้นตอนที่ 1: ใส่โค้ด Apps Script ใน Google Sheet
1. เปิดไฟล์ Google Sheet ของคุณ
2. ไปที่เมนูด้านบน คลิก **ส่วนขยาย (Extensions)** -> **Apps Script**
3. ลบโค้ดเดิมในหน้าต่าง `Code.gs` ออกทั้งหมด
4. คัดลอกโค้ดทั้งหมดจากไฟล์ `google-script/Code.gs` ในโปรเจกต์นี้ไปวางแทนที่

### ขั้นตอนที่ 2: Deploy เป็น Web App
1. ที่มุมขวาบนของหน้า Apps Script คลิกปุ่ม **ทำให้ใช้งานได้ (Deploy)** -> **การทำให้ใช้งานได้ใหม่ (New deployment)**
2. คลิกรูปเฟืองเลือกประเภทเป็น **เว็บแอป (Web app)**
3. ตั้งค่าดังนี้:
   - **คำอธิบาย (Description):** `Pre-Post Test API`
   - **เรียกใช้ในฐานะ (Execute as):** **ฉัน (Me)** *(อีเมลของคุณ)*
   - **ผู้มีสิทธิ์เข้าถึง (Who has access):** **ทุกคน (Anyone)** *(สำคัญมาก เพื่อให้พนักงานส่งสอบได้)*
4. คลิก **ทำให้ใช้งานได้ (Deploy)** และอนุมัติสิทธิ์ (Grant Access)
5. **คัดลอก URL ของ Web App** ที่ขึ้นต้นด้วย `https://script.google.com/macros/s/AKfycb.../exec`

### ขั้นตอนที่ 3: เชื่อมต่อ Web App URL กับหน้าเว็บข้อสอบ
1. เปิดหน้าเว็บข้อสอบ (`index.html`)
2. คลิกปุ่ม **Google Sheet Connected / ตั้งค่าการเชื่อมต่อ** ที่มุมขวาบน
3. นำ Web App URL ที่คัดลอกไว้มาวางในช่อง แล้วกด **บันทึกการตั้งค่า**
4. กดปุ่ม **ทดสอบการเชื่อมต่อ** ระบบพร้อมใช้งานทันที!

## 🚀 วิธีการทดสอบและรันระบบบนเครื่อง (Local Run)

คุณสามารถเปิดไฟล์ `index.html` ผ่านเว็บเบราว์เซอร์ (Chrome, Edge, Firefox) หรือเปิดรันผ่าน Dev Server เช่น VS Code Live Server / Python Simple HTTP Server ได้ทันที

```bash
# ตัวอย่างรัน HTTP Server ด้วย Python
python -m http.server 8080
```
แล้วเข้าเว็บบราวเซอร์ที่: `http://localhost:8080`
